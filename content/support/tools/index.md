Most of what we use in our research is open source, so you can read how a result was made, run it yourself and build on it. Nearly all of it is built on [GeoDMS](https://www.geodms.nl/), an open-source platform for large spatial models developed by [Object Vision](https://www.objectvision.nl/).

For GIS software and spatial data in general, see [support for researchers](/support/).

## Models

- [Land Use Scanner](/research/spatial-analysis-modelling/land-use-scanner-model/) simulates future land use. Its current version, RuimteScanner 2.0, is open source as [RSopen](https://www.geodms.nl/rsopen/).
- [CRISP](https://www.geodms.nl/crisp/) downscales population and built-up area to a 1 km grid worldwide. It produced the [localised projections in the UN's World Urbanization Prospects 2025](/news/world-urbanization-prospects/).
- [NetworkModel PBL](https://www.geodms.nl/networkmodel_pbl/) calculates accessibility by car, bicycle, foot and public transport for the Netherlands. There are also versions for [Europe](https://github.com/ObjectVision/NetworkModel_EU) and [the world](https://github.com/ObjectVision/NetworkModel_World/wiki).

## Tools for Dutch spatial data

- [BAG toolkit](/support/tools/bag-toolkit/) turns the national register of buildings and addresses into data you can model with, and geocodes your own address files.
- [Pand Hoogte Nederland](https://github.com/ObjectVision/PandHoogteNederland/wiki) gives every BAG building a height, derived from the AHN elevation data.
- [Price indices](https://github.com/jipclaassens/PriceIndices) calculates hedonic housing price indices from NVM transactions, which you need access to yourself. The method is described in [this memorandum](https://hdl.handle.net/1871.1/06a75545-3e5e-4a10-83ca-c5b35d3c2806).

## Learn how it works

- [Land Use Scanner, student edition](/support/tools/landusescanner/) is a working land-use model with its data, to experiment with.
- [GeoDMS Academy](https://www.geodms.nl/academy/) is a course in modules, from installing GeoDMS to starting your own project.
- [Land use modelling](https://github.com/ObjectVision/LandUseModelling/wiki) and [accessibility modelling](https://github.com/ObjectVision/AccessibilityModelling/wiki) are reference wikis on the methods, independent of any single project.

## Show your results

- [De Ronde Kaart](https://github.com/ObjectVision/DeRondeKaart) is an open-source web map for geospatial models, their data and the mathematical relations behind them.

## Older software

- [Definite](/support/tools/definite-bosda/) is decision support software for comparing a finite set of alternatives, developed at the VU in the 1990s.
