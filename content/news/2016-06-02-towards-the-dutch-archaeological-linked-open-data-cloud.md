Spinlab researcher Xander Wilcke is working on a solution to release archaeological knowledge that is now often stored on hard drives and only accessible by request.

The Archaeological Protocol 0102 provides a specification as to how rich XML summarizations, aptly named the pakbon (package slip in English), could and should be extracted from archaeological projects. Howevere, these remain isolated for now. Xander is working on a i>Linked data version of these pakbonnen.
